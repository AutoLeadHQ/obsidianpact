The Obsidian Pact SMP

A Vanilla+ Minecraft survival server for Java Edition. Real survival with no pay-to-win, plus an economy, homes, an RTP queue, events and proximity voice chat.

Server IP obsidianpact.net

Java Edition 26.1 – 26.3  •  Lunar Client works  •  Free to play  •  Hosted in the US (Dallas)

How to join

  1. Open Minecraft Java Edition (any 26.x version) and click Multiplayer.
  2. Click Add Server and type obsidianpact.net as the server address.
  3. Click Done, then Join Server. You start somewhere random in the world, ready to survive.
  4. Press Esc and click ⚔ Pact Menu (or type /menu) to see everything you can do.

What makes it Vanilla+

Economy and /shop

Buy and sell with /shop, sell a whole chest at once with /sell (you see the price before you confirm), and set up your own /quickbuy list.

Homes and teleports

Set 3 homes and give them names, use /tpa, and random teleport with /rtp in the overworld or the nether.

RTP Queue

Type /rtpq and get dropped into the world together with another player. Team up, or fight.

Safe trading

/trade lets two players swap items, XP and money in one window, so nobody gets scammed.

Proximity voice chat

With the Simple Voice Chat mod you hear players who are near you. Perfect for raids and ambushes.

Events

PvP, parkour and more in our own event arena. Events are announced in the Discord and in game.

PvP, raiding and griefing on

It's a real SMP: hide your base well. A 20-second combat tag stops people from teleporting out of fights.

Fair play

An anticheat and anti-xray keep things fair. No pay-to-win: the Obsidian+ rank is cosmetic plus extra homes.

Questions

What is the IP of The Obsidian Pact?

The IP is obsidianpact.net. play.obsidianpact.net works too.

Which Minecraft versions can join?

Java Edition 26.1, 26.2 and 26.3, including Lunar Client. Bedrock isn't supported.

Is it free?

Yes. There's an optional monthly Obsidian+ rank with cosmetic perks and more homes, and nothing that gives anyone a fighting edge.

Is PvP on?

Yes, everywhere outside events. Raiding and griefing are allowed too, so protect your stuff.

What's the [OG] tag?

Everyone who joins in the server's first week (until November 21, 2026) gets the [OG] tag forever.

How do I link my Discord?

Type /link in game, then type the code it gives you with /link in our Discord. You get $500 for linking.
